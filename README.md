## Featured Projects

### 🎓 [MAKAUT CampusSense](https://github.com/Srijita-Bhowmick/MAKAUT-CampusSense)

An **AI-powered academic and career resource platform** built around the needs of MAKAUT students. It brings academic information, syllabus resources, previous-year questions, and conversational assistance together in one place.

- Uses retrieval-augmented generation (RAG) and vector search to ground academic answers in relevant resources.
- Includes a conversational assistant with Gemini/Groq model fallback for queries beyond the local academic archive.
- Uses PostgreSQL with `pgvector` for vector storage, with an H2 development profile.

**Built with:** Java 21 · Spring Boot · PostgreSQL · pgvector · RAG · JavaScript · HTML · CSS · Docker

### 🗓️ [Schedulo](https://github.com/Srijita-Bhowmick/Schedulo)

A **deterministic university timetable scheduler** designed to generate conflict-free schedules while balancing practical constraints such as faculty availability, room allocation, lab duration, and student batches.

- Combines constraint satisfaction, backtracking, evolutionary strategies, and simulated annealing.
- Provides an interactive timetable matrix with batch, faculty, and room views.
- Supports schedule exports to PDF, Excel, and iCalendar formats.

**Built with:** TypeScript · React · Python · Vite · Tailwind CSS · Zustand · Web Workers
